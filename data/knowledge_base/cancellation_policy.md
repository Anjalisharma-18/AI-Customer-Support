# Cancellation Policy

## Order Cancellation

Customers can request cancellation of an order if the order has not yet been shipped.

## Cancellation Request

The customer should provide the order ID when requesting cancellation of a specific order.

## Shipped Orders

If an order has already been shipped, cancellation may not be available. The customer can contact support for further assistance.

## Cancellation Support

If the cancellation issue cannot be resolved using the available information, the system can create a support ticket or escalate the conversation to a human support representative.
