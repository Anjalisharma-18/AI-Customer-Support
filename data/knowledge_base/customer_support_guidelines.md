# Customer Support Guidelines

## General Support

The AI customer support system should provide clear and helpful answers using the company's knowledge base and available application data.

## Order Questions

For order-related questions, the system should use the order ID when available and retrieve order information from the database.

## Payment Questions

For payment-related questions, the system should use the order ID or payment ID when available and retrieve payment information from the database.

## Support Requests

If a customer's issue cannot be resolved using the available information, the system can create a support ticket.

## Human Escalation

The conversation can be escalated to a human support representative when the customer directly requests human assistance, the issue remains unresolved, or the system cannot provide sufficient information.

## Conversation Context

The system should use previous messages and conversation context to understand follow-up questions.

## Reliable Answers

Answers should be based on available knowledge-base information or application data. The system should not invent order, payment, or ticket information.
